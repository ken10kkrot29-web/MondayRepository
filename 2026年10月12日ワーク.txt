今日のコード
int main(void) {     Player player;     Enemy enemy;     player.hp = 100;     player.attack = 20;     enemy.hp = 50;     enemy.attack = 10;     player.Attack(enemy);     return 0; }
問題：
Player player;は何をしている？

Enemy enemy;は何をしている？

playerとPlayerは何が違う？

player.Attack(enemy);では何をしている？

なぜPlayerはEnemyを攻撃できる？

1.Player クラスをもとに、player というインスタンス（実体）を作成している。
このクラスの中にはHPや攻撃などのplayerが持つ変数がる。
・Player ：クラスの名前
・player ：作成したインスタンスの名前
・Player player; ：Playerクラスからインスタンスを作成する

2.Enemy クラスをもとに、enemy というインスタンスを作成している。（playerと同じことをしている。）
敵のHPと攻撃力を保存するための変数がある。
Player と Enemy は別々のクラスなので、それぞれのクラスから別のインスタンスを作成できます。
（playerとEnemyではそれぞれのクラスを持っている。）

3.Player はクラスの名前で、player はそのクラスから作成したインスタンスの名前です。
Player と player は、文字が違うため別の名前として扱われる。
クラスは情報や機能の設計図であり、インスタンスはその設計図から作成された実体。
| 名前       | 役割     | 意味               |
| `Player` | クラス    | プレイヤーの情報や機能を定義する |
| `player` | インスタンス | 実際に作成されたプレイヤー    |
| `hp`     | メンバ変数  | プレイヤーのHPを保存する    |
| `attack` | メンバ変数  | プレイヤーの攻撃力を保存する   |

4.player の Attack 関数を呼び出し、引数として enemy を渡しています。
player.Attack(enemy); は、Attack関数を呼び出すコード。
| コード      | 役割                      |
| `player` | 関数を呼び出すインスタンス           |
| `.`      | インスタンスのメンバにアクセスするための演算子 |
| `Attack` | 呼び出すメンバ関数の名前            |
| `enemy`  | 関数に渡す引数                 |

5.Player クラスに、敵を攻撃するための Attack 関数が定義されており、その関数に攻撃対象となる Enemy のインスタンスを渡しているからです。
Player クラスに Attack 関数が定義されている。
Attack 関数を使うには、Enemy クラスが適切に宣言されている必要があること。
（プレイヤーが敵を攻撃できるのは、プレイヤーのクラスに攻撃機能が用意されていて、その機能に攻撃対象を渡しているからです。）

インスタンスとは、クラスという設計図をもとに作った実体のこと！
（最初は「設計図」と「実際に作ったもの」の違いをイメージ。）
メンバー変数とは、クラスの中に定義された変数のこと。
